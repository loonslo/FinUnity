我们处理的数据

衡仓用于记录个人资产、账户、持仓、交易、目标配置和复盘数据。上述数据默认保存在设备本地数据库中。应用不要求注册登录，不建立衡仓云端用户账户，也不提供券商交易执行。

网络请求

当用户主动刷新行情或后台同步运行时，应用只向 FinUnity 专属服务请求证券价格、基金净值和汇率。请求可能包含证券代码、资产类型、基础币种和货币对，但不包含持仓数量、成本、账户余额或交易明细。专属服务负责连接实际数据源；返回数据可能延迟、缺失或修正，不构成投资建议。

截图识别

只有在用户明确确认后，选择的持仓截图才通过 HTTPS 发往位于新加坡的 FinUnity 专属服务器，再转交阿里云 DashScope（千问 qwen3.7-flash）识别。当前端点 dashscope.aliyuncs.com 的接入与数据存储地域为中国大陆（北京）；推理位置还取决于模型的服务部署范围，不由服务器位置单独决定。国际站 dashscope-intl.aliyuncs.com 的接入与存储地域为新加坡，未来切换前须核对账号、模型部署范围和可用性并更新政策。参见 阿里云地域说明。

FinUnity 仅在请求内存中处理原图，不写入服务器文件或数据库，请求结束后释放。匿名安装会话的结构化结果不写入服务端用户数据表，只在有容量上限的内存幂等缓存中最多保留 24 小时，可能因淘汰或重启提前失效；用户可取消导入，确认后数据保存在本机。安装标识的哈希与客户端 IP 用于防滥用额度，计数窗口最长 24 小时，后续请求会清理过期计数。

阿里云官方说明承诺不将客户数据用于模型训练，同时说明会依适用规则保存模型和应用调用产生的数据。FinUnity 不能承诺上游零留存或统一删除期限，上游保留与处理适用其条款。参见 阿里云百炼隐私说明及其中链接的服务协议。FinUnity 不用截图或本机账本数据训练模型。建议上传前遮挡姓名、账户号、证件号码等无关信息。

备份、保存与删除

用户可以在“备份恢复”中主动导出或恢复 JSON 文件。导出文件可能包含完整财务信息，属于明文文件，应只保存到可信位置。应用不使用 Android 自动云备份；删除应用或清空应用数据会移除本机数据库。

数据共享

除用户主动选择的行情请求、经确认的 DashScope 截图识别和系统文件选择器外，应用不向广告、分析或社交服务共享个人投资数据。应用不包含广告 SDK、登录 SDK 或第三方统计 SDK。
