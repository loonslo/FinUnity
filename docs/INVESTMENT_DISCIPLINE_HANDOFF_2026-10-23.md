# 投资纪律功能：Android整改对接

日期：2026-10-23。本轮只核对源码并形成对接方向，没有修改Android业务代码、Room数据库或Worker。跨端主方案与本地数据验收正本在FinUnityServer的 `docs/INVESTMENT_DISCIPLINE_PLAN_2026-10-23.md` 和 `docs/INVESTMENT_DISCIPLINE_ACCEPTANCE_2026-10-23.md`。

## 复用与边界

已有 `HoldingLedgerRepository`、交易来源指纹、备份迁移、Room和WorkManager，应优先复用。现有 `RecurringRule` 是月度收入/支出规则，不直接当投资定投成功记录；`ReviewReminderWorker` 的30天复盘提醒，也不是投资交易日的今日任务。

## 分批任务

- [ ] 对齐服务端的账户、资金池、持仓、可用/待结算现金和成交语义，核对单位成本与总成本、显式币种及负债。
- [ ] 接收版本化计划及稳定执行单ID，建立今日页：完成、待处理、可评估、待条件、今日无新增动作。
- [ ] 定投Worker只生成待办与预计占用，成功来自本人或成交确认。离线、重试、设备重启和补同步不能生成重复成功。
- [ ] 成交一次联动持仓/现金/额度；同步更正需可追溯，并处理与已有截图快照的重复计算。
- [ ] 通知以执行单和规则阶段去重，点击进入对应任务；无权限时保留应用内任务，不谎称已发通知。
- [ ] 参考、陈旧或时间不明的价格不能触发已满足买卖条件通知；交易时区、基金申购日和份额确认日分别保存。
- [ ] 新实体及字段必须补Room迁移、备份版本和恢复兼容，并验证旧快照不重放扣款。

私有初始记录本轮保存在服务端本地忽略目录，没有写入Android assets、演示数据库、APK、真实设备或线上账号。Android全流程、通知权限、离线恢复与真实设备测试尚未执行。
