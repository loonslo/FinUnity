# 界面精简与本月复盘验收

日期：2026-10-19。

## 问题与改动

- 草稿移除按钮原先位于表单底部，fieldset 标题穿过边框。现在标题与操作位于框内同一行，右侧固定显示“移除”；只剩一条时显示“清空”，保留可填写的空行。
- 建档各组移除按钮独占末行、右对齐；表单各列按输入框底边对齐。流水操作按钮不再受文本换行挤压。
- 简化重复说明与成功提示，来源、金额质量、核销和备注收进“更多选项”。金额增减预览、预测不入账和必要校验保留。成功提示可关闭，切换导航清除旧提示。
- 投入计划按三列展示计划、已投入、剩余；待开始明确显示“待投入”，不暴露内部方案 ID。检查型行动不再展示资金投入数字。
- 选择投入计划只替换未编辑的空白草稿；已输入备注、类型或日期等内容时另加一条，避免覆盖。
- 复盘只允许当前已确认方案的本月。服务在 SQLite 写事务内查找并更新同一方案、月份的文档，重复或并发调用不会新增多份。过去/未来月份和旧方案生成请求返回明确错误。
- 历史重复复盘不删除，仅合并显示最新一份。当前方案本月复盘单独展示，其余折叠在历史中；账目修订后提示更新。目标投入统计与行动进度一致，排除已包含在建档基准中的记录。

## 浏览器验证

使用 8012 独立虚构数据库，未向 8011 写入测试流水：

1. 输入收入 100、支出 20 两条草稿，预览方向分别为加、减；移除第一条，第二条金额和类型保留。
2. 首次生成复盘，再保存支出 20，页面提示更新；连续更新两次，始终只显示一份，支出为 20。
3. 未填金额但已写备注时点击投入计划，原备注保留，另加带目标与金额的投入草稿。
4. 检查建档移除按钮和记录表单的边框、对齐、折叠选项；既有重复复盘在 8011 页面由三份合并显示为一份。
5. 8011 服务更新前后，建档、修订号与流水规范化摘要一致，未改变财务事实。服务仅在 127.0.0.1:8011 提供，临时验收服务关闭。

## 验证边界

浏览器验证覆盖本机当前视口；小屏规则已核对，未运行独立移动设备或全部屏幕尺寸验收。未调用真实收费模型。历史重复复盘仍保存在数据库中，后续读取按方案与月份去重；不执行物理删除或数据迁移。
