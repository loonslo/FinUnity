## 浏览器实际流程

在 http://127.0.0.1:8011 使用内置虚构家庭，完成以下操作：

1. 从首页填入示例、检查建档并保存。
2. 生成待确认方案：学习目标显示 6000 CNY 缺口，长期目标在零收益条件下达到目标。
3. 确认了解缺口后采用方案，出现当月两条目标行动。
4. 记录一笔学习目标 2000 CNY 的实际投入转账，保存后关联完成学习行动。
5. 生成当月复盘：学习目标计划/实际均为 2000；长期目标实际尚无记录；转账未被计作收入；页面标注“无记录不代表实际为零”和“本月进行中”。
6. 返回首页，净资产保持 820000 CNY，现金为 98000 CNY，学习目标已分配金额增加到 22000 CNY，显示资料变化后应重新检查方案的提示。

首页截图保存为 prototype-overview.png。数据库中的这些示例不包含真实用户资料，保留在本机供继续体验，未提交到 Git。

最终服务重启并刷新页面后，示例方案、实际投入和目标进度仍然保留。JSON 导入预览通过同一份后端类型校验，预览失败不会保存或改变账目修订号。

## 验证环境修正

原始测试的三个供应商替身只替换默认 HTTP transport；本机存在代理路由时，该替身会被绕过。已在这三个测试 fixture 中清除代理 mounts，并在离线 fixture 中移除代理环境变量。变更只影响测试，不改变产品代理或模型策略。完整测试已在该隔离条件下通过，测试模型密钥为虚构值。

系统默认 pytest 临时目录存在访问限制，因此使用本项目内新建的唯一 `.test-runs/` 子目录执行。未修改系统权限，也未清理其他项目或系统测试目录。
